## Orion — flagship research thesis

**Orion is not a router. It is the cognitive governor.**

It interprets intent and governs execution with precision, autonomy, and systemic control — the cognitive fabric of the agentic stack, field-tested inside Orbit.

Public stance:

- Local-first / sovereignty-aware intelligence  
- Policy gates and scoped agents  
- Eval and verification as first-class  
- Explicit rejection of “wrap every model API and call it an OS”
